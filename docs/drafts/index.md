# Drafts and Works-in-Progress

This section contains research papers, design documents, and proposals under active development. These are not yet ratified or published in the main catalog, but are shared to gather community feedback and document thinking-in-motion.

## Current Drafts

Currently, all major ecosystem papers are in the main published catalog. As new drafts are developed, they will appear here.

## How to Contribute to Drafts

1. **You have an idea** - Write it as a draft in the `papers/drafts/` directory on GitHub and open a PR
2. **Comment on a draft** - Click the "💬 Comment / Collaborate" link to start a GitHub Discussion
3. **Move to published** - Once a draft receives community feedback and is ready for ratification or publication, it moves to the main Papers section

## Guidelines for Draft Authors

- Ground everything in verified sources (Doc NNN, code, on-chain data)
- Mark uncertain claims with `[to confirm]`
- Use the same style guide as published papers (no emojis, exact brand spellings)
- Include open questions and unknowns - that is the point of a draft
- Cite related ZIPs and research documents
